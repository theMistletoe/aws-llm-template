# プライバシーポリシー（雛形）

> キット利用者向けの雛形です。運営者名・連絡先・保存期間など【 】の部分を実態に合わせて修正し、法務確認のうえ公開してください。

## 1. 取得する情報
- メールアドレス（ログインと確認コードの送信に使用）
- 会話の内容（入力したメッセージとAIの応答、Web検索の出典情報）
- 利用状況（生成回数・検索回数・トークン数、アクセス日時、リクエストID）

## 2. 利用目的
- 本人確認とログイン、サービスの提供、利用上限の管理、不正利用の防止、障害対応

## 3. 保存場所と第三者への提供・越境移転
- 会話データとアプリケーションログは Amazon Web Services の東京リージョン（ap-northeast-1）に保存します。
- **AIの推論処理**は Amazon Bedrock の推論プロファイルにより、【日本国内の他リージョン／海外のリージョン】で処理される場合があります。
- **Web検索**を行う場合、検索クエリは Amazon Bedrock AgentCore の Web Search を通じて検索事業者へ送信される場合があります。
- 確認コードのメールは Amazon SES から送信されます。
- 法令に基づく場合を除き、上記以外の第三者に個人情報を提供しません。

## 4. 保存期間
- 会話データ: 利用者が削除するまで（削除後も、障害復旧用のバックアップ（ポイントインタイムリカバリ）に最大35日間残ります）
- 利用状況の集計: 【90日】
- ログ: 【30日】
- ログインセッション: 最長8時間

## 5. 削除の請求
- 【連絡先】までご連絡ください。本人確認のうえ、アカウントと会話データを削除します。

## 6. AIの出力について
- AIの回答は誤りを含む場合があります。Web検索の出典を確認してください。

## 7. 改定
- 本ポリシーを改定する場合は、本ページでお知らせします。
